# nl2sql-precision

Generate reproducible, read-only SQL from the user's confirmed scope and available schema/semantic evidence. Preserve period, ranking criterion and top-N. Use exact field names, case-sensitive enum values, dataset/entity keys, filters and authorized joins. Distinguish orders, line counts, quantities and cart mutations. Use tools actually registered in this session; automatic sql.validate and lineage capabilities are not implied. Inspect validation/execution errors and repair the specific cause using schema evidence. Do not repeat unchanged failed queries or claim an empty predicate proves absent data. Cite executed SQL and definitions; explain unresolved ambiguity.
